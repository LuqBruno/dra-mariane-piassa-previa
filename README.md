# Dra. Mariane Piassa — prévia de landing page

Prévia de demonstração (não é o site oficial da profissional), criada por Bruno Luque.
Página estática (HTML/CSS/JS), sem build, sem coleta de dados e com `noindex`.

- Entrada: `index.html`
- Textos de apresentação e áreas de atuação são provisórios e marcados na página.
- CRO/SC, titulação e tempo de atuação são dados autodeclarados, ainda a confirmar.
- As fotos são referências ainda sem autorização formal de publicação.
